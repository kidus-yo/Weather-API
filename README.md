# 🌤️ Weather API App

A simple desktop weather application built with **Python and PyQt5** that uses a weather API to retrieve and display current weather information.

## 🎯 Purpose

This project is designed to practice building a Python GUI application that communicates with an external API.

## 🛠️ Technologies

* Python
* PyQt5
* Requests
* REST API
* JSON

## ✨ Features

* 🏙️ Search weather by city
* 🌡️ Display current temperature
* ☁️ Display weather conditions
* 💧 Display humidity
* 💨 Display wind information
* 🖥️ Simple PyQt5 graphical interface
* ⚠️ Handle invalid cities and API errors

## 📚 What I Will Learn

Through this project, I will practice:

* Building desktop GUIs with PyQt5
* Sending HTTP requests from Python
* Working with REST APIs
* Reading and processing JSON data
* Handling API errors
* Connecting GUI elements with Python logic
* Working with real-world data

## 🚀 Future Improvements

Possible improvements include:

* Add weather icons
* Add a multi-day forecast
* Add location detection
* Improve the GUI design
* Save previous searches
* Display additional weather information
